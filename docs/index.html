✦ 미니미 광장
나만의 미니미를 만들고 친구들과 광장에 모여요.
불러도 대답 없는 친구에겐 화면 가득 불꽃놀이를 🎆
⬇ 맥용 다운로드
macOS 11 이상 · 애플 실리콘 / 인텔 모두 지원
  1. 받은 MinimiPlaza-mac.dmg 파일을 열어요.
  2. 미니미 광장 (MinimiPlaza) 아이콘을 응용 프로그램 폴더로 끌어다 놓아요.
  3. 응용 프로그램(Launchpad)에서 미니미 광장을 실행해요.
  4. 미니미를 만들고, 광장 코드를 친구에게 보내면 끝!
💡 창을 닫아도 메뉴 막대(오른쪽 위)에 ✦ 아이콘으로 남아 있어요. 그래야 친구가 부를 때 알림과 불꽃을 받을 수 있어요.
⬇ 윈도우용 다운로드
Windows 10 / 11 (64비트)
  1. 받은 MinimiPlaza-Setup.exe 를 실행해요.
  2. 파란 창 “Windows의 PC 보호”가 뜨면 추가 정보를 누르고 실행을 눌러요.
  3. 설치가 끝나면 미니미 광장이 자동으로 열려요.
  4. 미니미를 만들고, 광장 코드를 친구에게 보내면 끝!
💡 “PC 보호” 창은 새로 나온 프로그램이라 뜨는 거예요. 추가 정보 → 실행을 누르면 설치돼요.
창을 닫아도 작업 표시줄 오른쪽 트레이(^)에 ✦ 아이콘으로 남아 있어요.
